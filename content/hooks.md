# Hook-Katalog

Die ersten zwei Sekunden entscheiden. Jeder Hook im Kanal soll einem der
Muster unten folgen — bewusst gewählt, nicht spontan formuliert.

---

## Die Frage: reicht „Willkommen zu einem KI-Crashkurs"?

Ehrliche Einschätzung: **als alleiniger Hook nein, als Einstieg mit Nachsatz ja.**

Schau genau auf das Referenzvideo. Der Hook ist nicht „Let's do a Git crash
course". Der Hook ist:

> Let's do a Git crash course … **and no**, Git and GitHub are not the same thing.

Die Einladung eröffnet, aber der **Widerspruch** hält fest. Ohne den zweiten
Teil gibst du die wertvollste Sekunde für eine Ankündigung aus — der Zuschauer
erfährt, was kommt, aber keinen Grund zu bleiben.

**Aber du hast einen Punkt.** Betont trocken vorgetragen kann gerade die
Schlichtheit ein Musterbruch sein: alle anderen schreien „STOP SCROLLING", und
du sagst beiläufig „Willkommen zu einem KI-Crashkurs". Das ist eine echte
Wirkung und einen Test wert.

Deshalb: **beides**, nicht entweder-oder. Die Einladung als Rahmen, der
Widerspruch als Haken.

---

## Die fünf Muster

### 1. Einladung + Widerspruch (Standard)

> Kurzer KI-Crashkurs. Und nein — ein Agent ist kein Chatbot mit besserem Prompt.

Das Muster des Referenzkanals. Funktioniert immer, weil es Kontext gibt und
sofort eine Erwartung bricht. **Das ist der Standard, von dem abgewichen wird.**

### 2. Der widerlegte Allgemeinplatz

> Die KI hat kein schlechtes Gedächtnis. Sie hat gar keins.

Kein Rahmen, direkt die Behauptung. Härter, riskanter — funktioniert nur, wenn
der Irrtum wirklich verbreitet ist.

### 3. Die teure Konsequenz

> Dieser eine Fehler kostet dich bei jeder Anfrage Geld. Und du siehst ihn nicht.

Verlust schlägt Gewinn in der Aufmerksamkeit. Sparsam einsetzen, sonst wird es
Clickbait.

### 4. Die konkrete Szene

> Du fragst nach deinen Umsatzzahlen. Die KI antwortet. Und rät.

Der Zuschauer erkennt sich in einer Situation wieder, bevor er das Thema kennt.
Gut für Themen, die abstrakt klingen.

### 5. Die Zahl

> Dein Chat hat ein Limit. Ab Nachricht 40 vergisst er den Anfang.

Nur mit einer Zahl, die du belegen kannst. Sonst Muster 2 nehmen.

---

## Regeln

- **Kein „In diesem Video zeige ich dir…"** — das ist eine Ankündigung, kein Hook
- **Kein „STOP! Nicht weiterscrollen!"** — verbrannt, wirkt verzweifelt
- **Maximal zwei Sätze**, der zweite bricht die Erwartung des ersten
- **Das Suchwort gehört rein** — der Hook ist auch Ranking-Signal, Instagram
  wertet gesprochenes Audio aus
- **Betonung schlägt Formulierung.** Derselbe Satz trocken oder aufgeregt sind
  zwei verschiedene Hooks

---

## Wie du das testest

Sauberes A/B geht auf einem neuen Account **nicht** — zu wenig Reichweite,
und dasselbe Video zweimal zu posten wertet Instagram als Duplikat ab.

Stattdessen: **die ersten zehn Videos rotieren die Muster durch und du
protokollierst.**

| Video | Muster | Watch-Through | Saves/Views |
|---|---|---|---|
| 1 | 1 Einladung + Widerspruch | | |
| 2 | 2 Widerlegter Allgemeinplatz | | |
| 3 | 4 Konkrete Szene | | |
| 4 | 1 | | |
| … | | | |

Nach zehn Videos siehst du, welches Muster bei deinem Publikum trägt. Vorher
ist jede Zahl Rauschen — ein einzelnes gut laufendes Video sagt nichts über
seinen Hook aus.

Wichtig: **nur den Hook variieren, nicht gleichzeitig Länge, Thema und Stil.**
Sonst weißt du hinterher nicht, woran es lag.
