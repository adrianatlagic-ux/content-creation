# Caption — Agent vs. Chatbot

Video: `out/agent-vs-chatbot.mp4` (42 s)
Suchbegriffe im Fließtext: KI-Agent, Chatbot, Prompt, Werkzeuge

---

Ein KI-Agent ist kein Chatbot mit besserem Prompt. Der Unterschied ist die Schleife.

Ein Chatbot macht genau einen Durchlauf: Text rein, Text raus, fertig. Frag ihn nach deinen Umsatzzahlen — er rät. Deine Datei öffnen kann er nicht.

Ein Agent bekommt Werkzeuge: Dateien lesen, Befehle ausführen, im Netz suchen. Und dann läuft er in einer Schleife — denken, Werkzeug aufrufen, Ergebnis lesen, neu entscheiden. Findet er nichts, probiert er den nächsten Weg. Von allein.

Nicht das Modell macht den Unterschied. Die Schleife.

So nutzt du das konkret:

1️⃣ ZUGRIFF STATT BESCHREIBUNG

Häng die Datei an, statt ihren Inhalt zu beschreiben.

• ChatGPT → Büroklammer → Datei hochladen
• Claude → Projekt anlegen → Dateien ins Projektwissen
• Claude Code → liest dein Repo direkt, einfach den Pfad nennen

Ein Agent, der die Datei sehen kann, muss nicht raten.

2️⃣ ZIEL STATT EINZELSCHRITTE

Nicht: „Öffne Zeile 40 und schau, ob die Variable stimmt."
Sondern: „Finde den Fehler, der den Absturz verursacht."

Einzelschritte machen aus dem Agenten wieder einen Chatbot — du denkst, er tippt. Gibst du ein Ziel vor, sucht er selbst den Weg.

3️⃣ LASS IHN SCHEITERN

Das ist der Punkt, den fast niemand nutzt.

Wenn etwas nicht klappt, gib ihm die vollständige Fehlermeldung. Nicht „geht nicht", sondern den ganzen Text aus dem Terminal.

Ein Agent, der die Fehlermeldung sieht, korrigiert sich in der nächsten Runde selbst. Das ist die Schleife bei der Arbeit — und genau die verschenkst du, wenn du den Fehler zusammenfasst statt ihn weiterzugeben.

Wo hast du zuletzt selbst Schritte vorgegeben, die der Agent besser allein gefunden hätte?
