## Caption

Claude Code zeigt jetzt mehrere Design-Entwürfe zum direkten Anklicken — statt sie in Worten zu beschreiben.

Der `/design`-Skill legt mehrere Entwürfe nebeneinander auf eine Fläche. Klickst du einen an, wird er direkt bearbeitbar — mit echten Auswahl-Ecken wie in einem Design-Werkzeug, nicht als Screenshot zum Anschauen.

Drei Dinge, die du ab heute anders machst:

1️⃣ `/design` eintippen und kurz beschreiben, was du brauchst — z. B. „/design Login-Screen, hell und minimalistisch"
2️⃣ Einen der Entwürfe auf der Fläche anklicken und direkt anpassen
3️⃣ Claude sagen, welchen Entwurf es fertig umsetzen soll

Das Überraschendste daran: Jeder Entwurf ist von Anfang an ein editierbares Objekt, kein Bild — der Klick-Umweg über Text entfällt komplett, nicht nur beim ersten Entwurf.

Läuft aktuell als Research Preview auf Pro, Max, Team und Enterprise (nicht im Free-Plan) — Claude Code Version 2.1.234 oder neuer.

Wie oft hast du eine Design-Änderung schon in drei Sätzen beschrieben, nur um sie am Ende doch anders zu bekommen?
