## Caption

Deine Chat-Regeln musst du nicht jedes Mal neu tippen — in jedem Claude-Werkzeug gibt es dafür eine feste Stelle.

Dieser feste Text — dein System-Prompt — läuft bei jeder einzelnen Nachricht unsichtbar mit, wie der Vorspann einer Serie, der vor jeder Folge exakt gleich abläuft. Nur ist er keine Deko: Widersprichst du ihm, gewinnt meistens er.

Drei Orte, an denen du das einmal einträgst:

1️⃣ Claude.ai → Einstellungen → Profil: deine Regeln einmal eintragen
2️⃣ Bei einem Projekt → Projektwissen: gilt dann für alle Chats in diesem Projekt
3️⃣ Claude Code → eine Datei `CLAUDE.md` im Projektordner anlegen, wird automatisch mitgelesen

Das Überraschendste daran: Dieser unsichtbare Text hat mehr Gewicht als das, was du gerade tippst — bei einem Widerspruch setzt sich meistens er durch, nicht deine aktuelle Nachricht.

Steht bei dir schon irgendwo eine eigene Regel hinterlegt — und weißt du noch, welche?
