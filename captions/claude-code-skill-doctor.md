## Caption

Jede geladene Fähigkeit steht bei JEDER Nachricht im System-Prompt — egal, ob sie feuert oder nicht.

Bei fünf, zehn ungenutzten Skills frisst das leise Kontext, bevor du auch nur ein Wort geschrieben hast. Du siehst das nie direkt, nur die Kosten.

So findest und entfernst du die teuersten Karteileichen:

1️⃣ `/skill-doctor` eintippen — zeigt jede Fähigkeit, wie oft sie diese Sitzung gefeuert hat und wie viel Kontext sie kostet
2️⃣ `/skills` öffnen, die teuerste ungenutzte markieren
3️⃣ Leertaste zum Abschalten, Escape zum Speichern

Braucht Claude Code ab Version 2.1.252 — in älteren Versionen bleibt nur, Skills manuell in den Einstellungen zu deaktivieren.

Wie viele Skills hast du geladen, ohne noch zu wissen, wofür?
