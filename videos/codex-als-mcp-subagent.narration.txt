Claude Code und Codex laufen für dich komplett getrennt. Falsch — das eine ruft das andere mitten im selben Repo auf.
Dazwischen sitzt eigentlich ein kleiner MCP-Server. Der macht Codex zu einem Werkzeug, das Claude Code ganz normal aufruft — wie jedes andere MCP-Werkzeug auch.
Und deshalb sparst du dir halt das Wechseln zwischen zwei Fenstern. Claude Code schickt Aufgaben einfach an Codex weiter, notfalls auch parallel.
Technisch reicht das eigentlich so: Claude Code ruft spawn_agent mit einem Prompt auf. Der Server reicht ihn an Codex weiter — im selben Ordner, Codex schreibt direkt mit.
Aber Achtung, das läuft ohne Sandbox und ohne Rückfrage. Nur im eigenen, vertrauten Repo einsetzen.
Und so richtest du das ein: Codex einmal einloggen, den Server eintragen, mit Schrägstrich-MCP prüfen — und Codex direkt aus Claude Code heraus aufrufen.
Codex ist kein zweites Tool mehr. Es ist ein Werkzeug, das Claude Code bei Bedarf einfach mitnimmt.
